# Contributing to Heavy Engineers

Thank you for your interest in improving Heavy Engineers.

We welcome fixes, improvements, and thoughtful ideas that help the project grow.

## How to contribute

1. Fork the repository.
2. Create a feature branch.
3. Make your change.
4. Run the site locally to check the result.
5. Submit a pull request with a clear description.

## Local development

```bash
cd heavyengineers.github.io
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Content expectations

- Keep the site professional and consistent with the Heavy Engineers brand.
- Maintain responsive design and accessibility where possible.
- Avoid adding misleading claims or inaccurate business statements.
- Keep pull requests focused on a single improvement or fix.

## Reporting issues

Please use the GitHub issue templates when possible and include:

- the page or section affected
- what you expected
- what actually happened
- browser and device details if relevant

## Code of conduct

Please be respectful and constructive in all discussions. We aim to maintain a welcoming and professional project environment.
